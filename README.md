# 🐍 Python Mini IDE
A lightweight Python Integrated Development Environment (IDE) built with Tkinter.

## ✨ Features
* **Code Editor:** Write Python code with a clean interface.
* **Run Functionality:** Execute your scripts directly from the IDE.
* **File Management:** Open and Save your `.py` files easily.
* **Integrated Console:** View your output and errors in real-time.

## 🚀 How to Run
Since this is a desktop application, you must run it on your computer:
1. **Download** the `main.py` file from this repository.
2. Ensure you have **Python** installed.
3. Open your terminal/command prompt and run:
   ```bash
   python main.py
